# Wattwise

Wattwise is an energy analytics platform for UK small and medium-sized businesses. It ingests smart meter half-hourly consumption data and turns it into clear, actionable insight - helping business owners detect waste, verify their bills, benchmark against peers, and evaluate tariff options from a position of knowledge rather than dependence.

## This Repository

This repository is the central codebase for the Wattwise product. It currently contains the product documentation and design system. Application code will be added as development begins.

- `docs/` — product overview, PRD, and competitive landscape
- `design-system/` — design tokens, component previews, and React UI kit
